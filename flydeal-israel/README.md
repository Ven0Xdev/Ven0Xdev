# FlyDeal Israel ✈️🏨

מנוע השוואת **טיסות ומלונות** לישראלים — עברית מלאה, RTL, מחירים בשקלים, יציאה מנתב״ג (TLV).
נבנה כ-**Vanilla JS + HTML5 + CSS3** מודולרי, שעובד מיד בפתיחת `index.html` בדפדפן, ומוכן לחיבור עתידי ל-Backend ו-API אמיתיים.

> ⚠️ **מצב הדגמה (Demo):** ברירת המחדל היא `DATA_MODE = "mock"`. כל הנתונים המוצגים הם **נתוני הדגמה בלבד** ואינם מחירים אמיתיים. הם מסומנים בבירור בכל מקום באתר.

## הפעלה מהירה

**אפשרות 1 — פתיחה ישירה (הכי פשוט):**
פשוט פותחים את `index.html` בדפדפן. הפרויקט לא משתמש ב-ES Modules, ולכן עובד גם דרך `file://`.

**אפשרות 2 — שרת מקומי (מומלץ, מונע כל מגבלת דפדפן):**
```bash
cd flydeal-israel
python3 -m http.server 8080
# ואז בדפדפן: http://localhost:8080
```

אין צורך בהתקנות, אין תלות ב-npm, אין build.

## תכונות עיקריות

### חיפוש
- **שלושה טאבים:** טיסות · מלונות · חבילות (טיסה+מלון).
- טופס טיסות מלא: מוצא/יעד, הלוך-חזור/כיוון אחד (+Multi-City כהכנה), נוסעים (מבוגרים/ילדים/תינוקות), מחלקה, טיסה ישירה, מזוודה כלולה, חברות ישראליות בלבד, שעות יציאה מועדפות, גמישות תאריכים, מטבע.
- **Validation מלא בעברית:** יעד חובה, תאריך יציאה לא בעבר, חזרה אחרי יציאה, לפחות נוסע אחד ועוד.
- ברירות מחדל ישראליות: עברית, RTL, ILS, TLV, מבוגר אחד, הלוך ושוב.

### תוצאות
- **כרטיסי טיסה** מלאים: חברה + "לוגו", מספר טיסה, שעות, שדות תעופה, משך, עצירות, כבודה (תיק יד/קבינה/מזוודה), תנאי שינוי/ביטול, פירוט מחיר, ספק, זמן עדכון, ואימות מחיר.
- **כרטיסי מלון** מלאים: כוכבים, דירוג אורחים + מקור + מספר חוות דעת, מיקום ומרחקים, סוג חדר, מתקנים, תנאי ביטול/תשלום, מחיר סופי לכל השהייה + ממוצע ללילה.
- **המחיר הראשי בכרטיס הוא תמיד המחיר הסופי** (כולל מיסים, היטלים ועמלות חובה). תוספות אופציונליות מוצגות בנפרד.
- **תגיות:** הכי זול, המשתלם ביותר, המהיר ביותר, ישירה, כולל מזוודה, שינוי חינם, מחיר טוב ביחס לממוצע.
- **גרף מחירים** להשוואה ויזואלית מהירה בין חברות.

### סינון, מיון והשוואה
- מיון וסינון עשירים לטיסות ולמלונות (מחיר, חברה, עצירות, שעות, מתקנים, דירוג, ספק, חברות ישראליות תחילה ועוד).
- **השוואת עד 3** טיסות או מלונות בטבלה, עם הדגשת הערך הטוב ביותר בכל שורה.

### חוויית משתמש
- **Dark Mode** עם שמירה ב-LocalStorage.
- **מועדפים** ו**היסטוריית חיפוש** נשמרים מקומית.
- מצבי טעינה (Skeletons + אנימציית חיפוש), אין-תוצאות, שגיאה + ניסיון חוזר.
- Modal לפרטים מלאים, Toast Notifications, כפתור חזרה לראש, כפתור חיפוש דביק במובייל.
- תצוגת Grid/List, "טעינת עוד" (Pagination).

### שקיפות ואמינות
- הודעת שקיפות קבועה באזור התוצאות.
- כל תוצאה מציגה: זמן עדכון, מקור נתונים, ספק, האם המחיר אומת.
- הודעות "נותרו מעט מקומות" מוצגות **רק** כאשר המידע קיים במקור (אחרת `null` — לא מוצג). **אין לחצי דחיפות מזויפים ואין ביקורות מומצאות.**

## מצבי נתונים (DATA_MODE)

מוגדר ב-`config.example.js` (העתיקו ל-`config.js` והתאימו):

| מצב | תיאור |
|-----|--------|
| `mock` | **ברירת מחדל.** נתוני הדגמה בלבד, מסומנים בבירור. אין קריאות רשת. |
| `api` | מציג **אך ורק** נתונים שהתקבלו מ-API אמיתי דרך ה-Backend שלכם. |
| `hybrid` | מתחיל ב-mock ומאפשר החלפה ל-API כשמוגדר (למשל fallback). |

שכבת ה-Services בנויה כך שהחלפת המצב לא דורשת שינוי בשאר האפליקציה — רק החלפת ה-Provider.

## חיבור API אמיתי — חוקי ובטוח

### עקרון הזהב 🔑
**לעולם אין להטמיע מפתחות API בקוד ה-Frontend.** מפתחות חשופים לכל מבקר באתר.
כל קריאה לספק חייבת לעבור דרך **Backend / Serverless Function** שבבעלותכם, ששם נשמרים המפתחות.

```
Browser (Frontend)  ──►  ה-Backend שלכם (proxy)  ──►  ספק ה-API (Amadeus/Duffel/…)
   config.js               מחזיק את המפתחות              מחזיר נתונים
```

### ספקים חוקיים אפשריים
- **טיסות:** [Amadeus Self-Service](https://developers.amadeus.com/), [Duffel](https://duffel.com/), [Travelpayouts](https://www.travelpayouts.com/) (Affiliate).
- **מלונות:** Booking.com Affiliate Partner API, Expedia Rapid API, [Hotelbeds](https://developer.hotelbeds.com/).
- יש לחתום/להירשם לתוכניות הרשמיות ולעמוד בתנאי השימוש של כל ספק.

> **אין לבצע Scraping לא חוקי** מאתרי תיירות. השתמשו רק ב-API רשמיים, ספקי Affiliate מורשים או מקורות נתונים שהשימוש בהם מותר.

### איך מחברים בקוד
1. ממשק ה-Provider כבר מוגדר בשירותים:
   - **טיסות:** `searchFlights(params)`, `getFlightDetails(id)`, `normalizeFlight(raw)`, `getBookingUrl(id)`.
   - **מלונות:** `searchHotels(params)`, `getHotelDetails(id)`, `normalizeHotel(raw)`, `getBookingUrl(id)`.
2. השלימו את `RealFlightProvider` / `RealHotelProvider` (שלד קיים בקבצי השירות) כך שיקראו ל-`config.apiBaseUrl` (ה-Backend שלכם), וימפו את תגובת הספק לפורמט האחיד ב-`normalize*`.
3. שנו `DATA_MODE` ל-`api` (או `hybrid`).

### דרישות פרודקשן (Backend)
- שמירת מפתחות API בצד השרת (Environment Variables / Secret Manager).
- **Rate Limiting** למניעת שימוש לרעה.
- **Caching** של תוצאות (מחירים משתנים — הגדירו TTL סביר).
- **Logging** ו-**Error Handling** מסודרים.
- הגנה מפני abuse (CAPTCHA/חתימות/הרשאות לפי צורך).
- בדיקת **תנאי השימוש** של כל ספק (אחסון מחירים, תדירות קריאות, אזכור מותג).

## חישובי מחיר

כל החישובים מרוכזים בשירותים, עם **הפרדה מוחלטת** בין חובה לאופציונלי:

```
מחיר סופי (טיסה, לאדם) = basePrice + mandatoryTaxes + mandatoryFees + selectedExtras
מחיר סופי (מלון, לשהייה) = (perNight × nights) + taxes + fees
```

- `Mandatory Fees` נכללים תמיד במחיר הראשי המוצג.
- `Optional Extras` (מושב, מזוודה נוספת) מוצגים בנפרד ולא "מתחבאים" בכותרת.
- עיצוב מחירים באמצעות `Intl.NumberFormat("he-IL", { style:"currency" })`.
- המרת מטבע מרוכזת ב-`currency-service.js` (במצב אמיתי — שערים ממקור רשמי).

**טיסות:** `45% מחיר סופי · 20% משך · 15% עצירות · 10% כבודה · 10% גמישות שינוי/ביטול`

הציון מנורמל 0–100 מול קבוצת התוצאות הנוכחית, ולכל עסקה מוצג **הסבר קצר** מדוע קיבלה דירוג גבוה.

## אבטחה

- **מניעת XSS:** בניית DOM דרך `Utils.el()` עם `textContent` — **אין** שימוש ב-`innerHTML` עם מידע לא מאומת (רק עם אייקוני SVG שאנחנו יוצרים).
- ניקוי קלט משתמש (`Utils.sanitize`), Validation בצד הלקוח (ומוכן להרחבה בצד השרת).
- קישורים חיצוניים עתידיים: הוסיפו `rel="noopener noreferrer"` ל-`target="_blank"`.
- **אין מפתחות API** ב-Frontend. `config.example.js` מכיל שמות משתנים בלבד.
- דוגמת **Content Security Policy** מתועדת ב-`index.html` (מיועדת להפעלה כ-HTTP Header בפרודקשן).

## ביצועים ונגישות

- קוד מודולרי ונקי, ללא ספריות חיצוניות כבדות.
- אייקונים כ-SVG מוטבע ותמונות מלון כגרדיאנטים — **אין תמונות שבורות ואין Layout Shift**.
- `Debounce` על מסנני מחיר.
- נגישות: ניווט מקלדת מלא, `aria-label`/`aria-live`/`role`, ניגודיות טובה, focus-trap ב-Modal, כיבוד `prefers-reduced-motion`, ותמיכה ב-`prefers-color-scheme`.
- SEO בסיסי: Meta Tags, Open Graph, Twitter Card, Schema.org (`TravelAgency` + `SearchAction`), `robots.txt` ו-`sitemap.xml` לדוגמה.
